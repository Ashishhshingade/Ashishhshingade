# About Me

I'm a Software Developer / Data Engineer with 2+ years of experience building scalable ETL pipelines and data integrations for a global hedge fund managing $50B+ AUM.

I design and orchestrate data workflows using **Apache Airflow** and **Alteryx**, work across **AWS (S3, EC2, Glue)** for cloud based data solutions, and turn high volume daily trading data into actionable business insights combining backend engineering (**Python, SQL**) with BI visualization (**Tableau, Power BI, SSRS**).

-  Experienced in building and maintaining production ETL pipelines and data warehouses
-  I build dashboards and reports that directly support real investment/business decisions
-  Working knowledge of AWS and Databricks for large scale data processing
-  Firm believer that understanding your data deeply matters more than just knowing the tools
-  Open to collaborations, opportunities, and interesting data engineering problems
